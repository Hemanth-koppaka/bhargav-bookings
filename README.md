07 — CRITICAL MEN / WOMEN SEPARATION

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

THIS IS A STRICT PRODUCT RULE.

MEN AND WOMEN MUST HAVE COMPLETELY SEPARATE BOOKING FLOWS.

Once MEN is selected:

• Only Men's categories appear

• Only Men's services appear

• Only relevant Men's booking options appear

Once WOMEN is selected:

• Only Women's categories appear

• Only Women's services appear

• Only relevant Women's booking options appear

THE TWO SERVICE MENUS MUST NEVER MIX.

No accidental crossover.

No Women's services inside Men's booking.

No Men's services inside Women's booking.

The selected audience should remain stored throughout the booking journey.

The user can only change Men/Women by intentionally going Back to the selection screen.

Do not silently reset their selection.
